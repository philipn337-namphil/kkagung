## 확정 규칙

- 오전 8시에 운세와 추천 카드를 갱신하며, 다음 날 8시 전까지 유지한다.
- 운세는 카드 수(3·5·7장), 인기 배지 카드와 조건 일치 카드의 구성 비율만 바꾼다. 외모·매력은 AI가 판정하지 않는다.
- 실제 사진은 비공개로 저장하고, 추천 카드에는 AI 변환 또는 서버 생성 흐림 이미지만 공개한다.
- 채팅 요청 수락 시 양쪽에게 동시에 실제 사진과 상세 프로필을 공개한다.
- 운세 확인 선착순 N명(기본 100명)에게만 당일 새로고침권을 지급한다.
- 인기 배지는 최근 30일의 고유 하트·채팅 요청 수를 기준으로 부여하며 수치는 노출하지 않는다.
