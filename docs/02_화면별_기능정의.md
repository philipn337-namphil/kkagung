# 화면별 기능 정의

## 사용자 화면

| 화면 | 주요 기능 |
|---|---|
| 가입·성인 인증 | 계정 생성, 성인 인증, 미성년·중복 계정 차단 |
| 프로필 등록 | 필수 정보·실제 사진 1~3장·선택 정보 입력, AI 공개 이미지 생성 상태 확인 |
| 선호 조건 | 성별·나이(필수), 지역·특성·취미(상관없음 가능) 설정 |
| 홈 | 오늘 운세, 카드 3·5·7장, 새로고침권 상태, 하트·채팅 요청 |
| 카드 상세 | 공개 정보·추천 이유 확인, 하트·메시지 요청 |
| 받은 하트 | 발신자 공개 카드 확인, 역방향 채팅 요청·차단 |
| 받은 요청 | 수락·거절·무시·신고·차단; 수락 시 채팅방 생성 |
| 채팅방 | 수락 후 공개 프로필(이름·실제 사진 포함), 메시지, 신고·차단 |
| 마이페이지 | 프로필·선호 수정, 사진 재업로드, 차단 목록, 탈퇴 |

## 관리자 화면

| 화면 | 주요 기능 |
|---|---|
| 대시보드 | 가입, 운세 조회, 카드 조회, 하트, 채팅 요청, 신고, 선착순 재고 확인 |
| 사용자 목록·제재 | 경고, 추천 제외, 채팅 제한, 이용 정지·해제 |
| 신고 목록 | 신고 확인, 처리 결과 기록, 제재 연결 |
| 배지 기준 설정 | 최근 30일 고유 하트·요청 기준 저장 |
| 선착순 인원 설정 | 다음 일자의 새로고침권 N 설정(기본 100) |

```text
가입·인증 → 프로필 등록 → 선호 조건 → 홈 → 카드 상세 → 하트/채팅 요청
받은 하트 → 카드 상세 → 채팅 요청
받은 요청 → 수락 → 채팅방
관리자 대시보드 → 사용자·신고·배지·선착순 설정
```
