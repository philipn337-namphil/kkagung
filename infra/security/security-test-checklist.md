## 관리자 API

- [ ] 모든 `/api/v1/admin/*` API: 무토큰·위조·만료 토큰은 401.
- [ ] 모든 관리자 API: 일반 사용자·권한 회수·정지·탈퇴 계정은 403.
- [ ] 허용 IP의 활성 관리자만 정상 동작한다.
- [ ] 허용되지 않은 IP, 일반 사용자 도메인, 직접 서버 주소로 접근해도 우회되지 않는다.
- [ ] `X-Forwarded-For` 위조로 IP 제한을 우회할 수 없다.
- [ ] 일반 가입·프로필 변경으로 관리자 권한·성인 인증 상태를 설정할 수 없다.
- [ ] 잘못된 설정값은 거부되고 선착순 N 변경은 다음 서비스 날짜부터 적용된다.
- [ ] 제재·신고 처리·설정 변경의 감사 로그에 작업자·대상·변경 전후·결과가 남는다.
- [ ] 로그인 반복 실패에 속도 제한이 적용된다.

## 사진·채팅

- [ ] 원본 버킷의 익명 다운로드·목록 조회가 거부된다.
- [ ] 카드·받은 하트·받은 요청 응답에 원본 URL·객체 키가 없다.
- [ ] 본인은 자신의 원본만 조회할 수 있다.
- [ ] A→B 요청 대기·거절·무시 상태에서 상대 원본 조회가 거부된다.
- [ ] B가 수락하면 A·B만 서로의 원본을 조회할 수 있다.
- [ ] C가 사용자 ID·사진 ID·방 ID를 바꿔도 사진·메시지를 조회하거나 전송할 수 없다.
- [ ] 요청 발신자·제3자가 수신자 대신 채팅 요청을 수락할 수 없다.
- [ ] 차단 후 새 사진 URL·요청·메시지가 차단되고 기존 메시지는 참여자만 조회한다.
- [ ] 정지·탈퇴 계정의 기존 토큰도 서비스 접근이 차단된다.
- [ ] 원본 URL은 최대 60초 후 만료되고 응답·중간 캐시에 저장되지 않는다.
- [ ] 공개 AI/흐림 파일은 원본과 별도 객체이며 메타데이터·썸네일에 원본이 없다.
- [ ] AI 및 흐림 생성 실패 시 원본으로 대체하지 않는다.
- [ ] 비이미지 파일·과대 파일·타인 경로 업로드가 거부된다.
